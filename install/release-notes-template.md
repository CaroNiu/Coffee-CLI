### Coffee CLI v3.5.8

市面上有很多 AI 终端工具推出了自己的移动端 App。我们认为，在手机上手动操作终端、切换窗口和查看进度，仍然费时费力。Coffee CLI 选择消息网关与内置 Coffee Agent：通过熟悉的微信或 Telegram 发出指令，让 Agent 读取所有 CLI 终端的实际文字、安排任务并汇报进度，在手机上继续接管工作。v3.5.8 延续上一版的移动使用方式，进一步打磨对话体验与多语言支持。

- **通过消息管理真实终端。** 指定 Claude Code、Codex 等工具与工作目录，打开桌面真实可见的终端标签，通过 Gambit 派发任务、查看进度或继续历史工作。
- **手机与电脑共享持续对话。** 延续 v3.5.7 的本地对话记录、长对话摘要与工作偏好记忆，在微信或 Telegram 聊过的内容，也可以从电脑上的会话记录打开继续。
- **Coffee Agent 界面支持 11 种语言。** 消息设置、使用说明、渠道状态、提示与错误信息随界面语言切换。
- **复用 CLI 泡泡对话界面。** 用户消息在右侧，Agent 回复在左侧；共用侧边对话导航与消息复制按钮，快速定位每轮提问、复制消息内容。
- **阅读历史更稳定。** 查看旧消息时，新回复不会把页面拉回末尾；加载更早记录时保留当前阅读位置。
- **英文派发更顺畅。** 你用自己的语言与 Coffee Agent 沟通，它整理任务并用英文派发给其他 CLI Agent，再用你的语言汇报；关闭后也用你的语言派发。开关静默自动保存，修复切换时文字抖动，并精简使用说明。

消息连接功能仍在完善，使用中可能遇到问题。欢迎通过 [GitHub Issues](https://github.com/edison7009/Coffee-CLI/issues) 提交问题、意见和建议，帮助我们改善这套工作方式。

### Coffee CLI v3.5.8

Many AI terminal tools offer their own mobile apps. We believe manually operating terminals, switching windows, and checking progress on a phone still takes time and effort. Coffee CLI chooses a message gateway with the built-in Coffee Agent: send instructions through familiar WeChat or Telegram conversations, and the agent reads the actual text of all CLI terminals, assigns tasks, and reports progress. Keep managing your work from your phone. v3.5.8 builds on the previous release's mobile workflow with a more polished conversation experience and broader language support.

- **Manage real terminals through messages.** Specify tools such as Claude Code or Codex and a working directory to open visible desktop terminal tabs. Delegate tasks through Gambit, check progress, or resume previous work.
- **Continue conversations across phone and computer.** Keep the local conversation history, long-conversation summaries, and work preference memory introduced in v3.5.7. Reopen WeChat or Telegram conversations from desktop session history and continue there.
- **Coffee Agent UI in 11 languages.** Message settings, help, channel status, prompts, and error messages follow your interface language.
- **Reuse the CLI bubble conversation view.** User messages appear on the right and Agent replies on the left. Shared side navigation and copy buttons let you jump to each question and copy message content.
- **Read history without losing your place.** New replies no longer pull you to the bottom while you read earlier messages. Loading older records preserves your reading position.
- **Smoother English delegation.** Talk to Coffee Agent in your own language; it prepares tasks in English for other CLI agents and reports back in your language. Turn the switch off to delegate in your language as well. The switch saves silently, its text no longer shifts during saving, and the help text is shorter.

Message connections are still being refined, and you may encounter issues. Please share problems, ideas, and suggestions through [GitHub Issues](https://github.com/edison7009/Coffee-CLI/issues) to help us improve this workflow.

### Coffee CLI v3.5.8

多くの AI ターミナルツールが独自のモバイルアプリを提供しています。しかし、スマートフォンでターミナルを手動操作し、ウィンドウを切り替えて進捗を確認するには、依然として時間と手間がかかると考えています。Coffee CLI は、メッセージゲートウェイと内蔵 Coffee Agent を採用しました。使い慣れた WeChat や Telegram で指示を送ると、Agent がすべての CLI ターミナルに実際に表示されている文字を読み取り、タスクを割り振って進捗を報告します。スマートフォンから仕事を引き継げます。v3.5.8 では前バージョンのモバイルでの使い方を引き継ぎ、会話体験と多言語対応をさらに改善しました。

- **メッセージから実際のターミナルを管理。** Claude Code や Codex などのツールと作業ディレクトリを指定すると、デスクトップに実際に表示されるターミナルタブを開けます。Gambit でタスクを依頼し、進捗を確認したり、過去の作業を再開したりできます。
- **スマートフォンとパソコンで会話を継続。** v3.5.7 で導入したローカルの会話履歴、長い会話の要約、作業上の好みの記憶を引き続き利用できます。WeChat や Telegram の会話をパソコンのセッション履歴から開いて続けられます。
- **Coffee Agent の UI を 11 言語に対応。** メッセージ設定、使用説明、接続状態、案内、エラーメッセージが UI の言語に合わせて切り替わります。
- **CLI と同じ吹き出し表示を採用。** ユーザーのメッセージは右側、Agent の返信は左側に表示されます。共通のサイドナビゲーションとコピーボタンで各質問へ移動し、メッセージ内容をコピーできます。
- **履歴を読んでいる位置を維持。** 過去のメッセージを読んでいる間、新しい返信で末尾へ戻されなくなりました。さらに古い履歴を読み込んでも、現在の閲覧位置を保ちます。
- **英語でのタスク依頼を改善。** 自分の言語で Coffee Agent と会話すると、Agent がタスクを整理して英語でほかの CLI Agent に依頼し、自分の言語で結果を報告します。オフにすると依頼にも自分の言語を使います。切り替えは表示を変えずに自動保存され、保存中に文字が動く問題を修正しました。使用説明も簡潔にしました。

メッセージ接続機能は引き続き改善中で、問題が発生する場合があります。[GitHub Issues](https://github.com/edison7009/Coffee-CLI/issues) から不具合、ご意見、ご提案をお寄せください。この作業方式の改善に役立てていきます。

### Coffee CLI v3.5.8

많은 AI 터미널 도구가 자체 모바일 앱을 출시하고 있습니다. 하지만 휴대폰에서 터미널을 직접 조작하고, 창을 전환하며 진행 상황을 확인하는 데는 여전히 시간과 노력이 든다고 생각합니다. Coffee CLI는 메시지 게이트웨이와 내장 Coffee Agent를 선택했습니다. 익숙한 WeChat이나 Telegram에서 지시를 보내면 Agent가 모든 CLI 터미널에 실제로 표시된 텍스트를 읽고, 작업을 배정하며 진행 상황을 알려 줍니다. 휴대폰에서 계속 작업을 관리할 수 있습니다. v3.5.8은 이전 버전의 모바일 사용 방식을 이어가며 대화 경험과 다국어 지원을 개선했습니다.

- **메시지로 실제 터미널 관리.** Claude Code나 Codex 같은 도구와 작업 디렉터리를 지정하면 데스크톱에 실제로 보이는 터미널 탭이 열립니다. Gambit으로 작업을 전달하고, 진행 상황을 확인하거나 이전 작업을 이어갈 수 있습니다.
- **휴대폰과 컴퓨터에서 대화 이어가기.** v3.5.7에서 도입한 로컬 대화 기록, 긴 대화 요약, 작업 선호 사항 기억을 계속 지원합니다. WeChat이나 Telegram에서 나눈 대화를 컴퓨터의 세션 기록에서 열어 이어갈 수 있습니다.
- **Coffee Agent UI 11개 언어 지원.** 메시지 설정, 사용 설명, 채널 상태, 안내, 오류 메시지가 인터페이스 언어에 맞춰 바뀝니다.
- **기존 CLI 말풍선 대화 화면 활용.** 사용자 메시지는 오른쪽, Agent 답변은 왼쪽에 표시됩니다. 공통 측면 탐색과 복사 버튼으로 각 질문으로 이동하고 메시지 내용을 복사할 수 있습니다.
- **기록을 읽던 위치 유지.** 이전 메시지를 읽는 동안 새 답변이 와도 화면이 맨 아래로 이동하지 않습니다. 더 오래된 기록을 불러올 때도 현재 읽는 위치를 유지합니다.
- **더 편해진 영어 작업 전달.** 자신의 언어로 Coffee Agent와 대화하면 Agent가 작업을 정리해 영어로 다른 CLI Agent에 전달하고, 자신의 언어로 결과를 알려 줍니다. 스위치를 끄면 작업도 자신의 언어로 전달합니다. 화면 표시를 바꾸지 않고 자동 저장하며, 저장 중 글자가 흔들리던 문제를 수정했습니다. 사용 설명도 간결하게 다듬었습니다.

메시지 연결 기능은 계속 개선 중이며, 사용 중 문제가 발생할 수 있습니다. [GitHub Issues](https://github.com/edison7009/Coffee-CLI/issues)에 문제, 의견, 제안을 남겨 이 작업 방식을 개선하는 데 함께해 주세요.
