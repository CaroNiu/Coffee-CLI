### Coffee CLI v3.5.7

不少 AI 终端工具选择推出自己的移动端 App。我们认为，在手机上继续手动操作终端、切换窗口和查看进度，仍然费时费力。因此，Coffee CLI 选择消息网关与 Coffee Agent：你通过熟悉的微信或 Telegram 说明需求，由 Agent 读取本机各个 CLI 终端的实际文字画面、协调工具并汇报进度。

- **新增 Coffee Agent 与消息设置。** 单独配置内置 Agent 的模型，支持微信扫码连接与 Telegram Bot 配对。
- **远程操作真实终端。** 指定工具与工作目录，打开桌面可见的终端标签，通过 Gambit 派发任务或继续历史会话；回到电脑后可以直接接管。
- **手机与桌面继续同一段对话。** 历史对话本地持久保存，可从桌面会话记录打开继续；长对话自动整理为摘要，支持记住、查看和忘记工作偏好。
- **新增英文派发开关。** 你用自己的语言沟通，Coffee Agent 默认用英文向其他 CLI Agent 派发任务，再用你的语言汇报；关闭后，任务派发也默认使用你的语言。
- **其他改进。** 支持 OpenCode V2 会话记录与热力图，改善会话历史的缓存恢复，以及多终端大量输出时的解析与调度稳定性。

消息连接功能仍在完善，使用中可能遇到问题。欢迎通过 [GitHub Issues](https://github.com/edison7009/Coffee-CLI/issues) 提交问题、意见和建议，帮助我们改善这套工作方式。

### Coffee CLI v3.5.7

Many AI terminal tools offer their own mobile apps. We believe manually operating terminals, switching windows, and checking progress on a phone still takes time and effort. Coffee CLI takes a message gateway approach with Coffee Agent: describe your needs in WeChat or Telegram, and the agent reads the actual text displayed by your local CLI terminals, coordinates tools, and reports progress.

- **Add Coffee Agent and message settings.** Configure a separate model for the built-in agent, connect WeChat by scanning a QR code, or pair a Telegram bot.
- **Control real terminals remotely.** Choose a tool and working directory to open a visible desktop terminal tab, delegate tasks through Gambit, or resume a saved session. Take over directly when you return to your computer.
- **Continue the same conversation on phone and desktop.** Conversations persist locally and can be reopened from desktop session history. Long conversations are automatically summarized, with support for remembering, reviewing, and forgetting work preferences.
- **Add an English delegation switch.** Communicate in your own language while Coffee Agent delegates tasks to other CLI agents in English by default and reports back in your language. Turn it off to delegate in your language by default as well.
- **Other improvements.** Support OpenCode V2 session history and heatmaps, improve history cache restoration, and stabilize parsing and scheduling when multiple terminals produce large amounts of output.

Message connections are still being refined, and you may encounter issues. Please share problems, ideas, and suggestions through [GitHub Issues](https://github.com/edison7009/Coffee-CLI/issues) to help us improve this workflow.

### Coffee CLI v3.5.7

多くの AI ターミナルツールが独自のモバイルアプリを提供しています。しかし、スマートフォンでターミナルを手動操作し、ウィンドウを切り替えて進捗を確認するには、依然として時間と手間がかかると考えています。そこで Coffee CLI は、メッセージゲートウェイと Coffee Agent を採用しました。使い慣れた WeChat や Telegram で要望を伝えると、Agent がローカルの各 CLI ターミナルに実際に表示されている文字を読み取り、ツールを連携させて進捗を報告します。

- **実際のターミナルを遠隔操作。** ツールと作業ディレクトリを指定してデスクトップに表示されるターミナルタブを開き、Gambit でタスクを依頼したり、過去のセッションを再開したりできます。パソコンに戻れば、そのまま操作を引き継げます。
- **スマートフォンとデスクトップで同じ会話を継続。** 会話履歴をローカルに保存し、デスクトップのセッション履歴から開いて続けられます。長い会話は自動的に要約し、作業上の好みを記憶・確認・削除できます。
- **英語でのタスク依頼を切り替え。** 自分の言語で会話し、Coffee Agent は既定で英語を使ってほかの CLI Agent にタスクを依頼し、自分の言語で結果を報告します。オフにすると、タスクの依頼にも既定で自分の言語を使います。
- **その他の改善。** OpenCode V2 のセッション履歴とヒートマップに対応。履歴キャッシュの復元と、複数ターミナルで大量の出力が発生する際の解析・スケジューリングの安定性を改善しました。

メッセージ接続機能は引き続き改善中で、問題が発生する場合があります。[GitHub Issues](https://github.com/edison7009/Coffee-CLI/issues) から不具合、ご意見、ご提案をお寄せください。この作業方式の改善に役立てていきます。

### Coffee CLI v3.5.7

많은 AI 터미널 도구가 자체 모바일 앱을 출시하고 있습니다. 하지만 휴대폰에서 터미널을 직접 조작하고, 창을 전환하며 진행 상황을 확인하는 데는 여전히 시간과 노력이 든다고 생각합니다. 그래서 Coffee CLI는 메시지 게이트웨이와 Coffee Agent를 선택했습니다. 익숙한 WeChat이나 Telegram에서 요구 사항을 전달하면 Agent가 로컬의 각 CLI 터미널에 실제로 표시된 텍스트를 읽고, 도구를 조율하며 진행 상황을 알려 줍니다.

- **Coffee Agent와 메시지 설정 추가.** 내장 Agent의 모델을 별도로 설정하고, QR 코드로 WeChat을 연결하거나 Telegram Bot을 페어링할 수 있습니다.
- **실제 터미널 원격 조작.** 도구와 작업 디렉터리를 지정해 데스크톱에 보이는 터미널 탭을 열고, Gambit으로 작업을 전달하거나 이전 세션을 이어갈 수 있습니다. 컴퓨터로 돌아오면 바로 이어서 조작할 수 있습니다.
- **휴대폰과 데스크톱에서 같은 대화 이어가기.** 대화 기록을 로컬에 저장하고 데스크톱 세션 기록에서 다시 열어 이어갈 수 있습니다. 긴 대화는 자동으로 요약하며, 작업 선호 사항을 기억하고 확인하거나 잊도록 요청할 수 있습니다.
- **영어 작업 전달 스위치 추가.** 자신의 언어로 대화하면 Coffee Agent가 기본적으로 영어로 다른 CLI Agent에 작업을 전달하고, 자신의 언어로 결과를 보고합니다. 끄면 작업 전달에도 기본적으로 자신의 언어를 사용합니다.
- **기타 개선.** OpenCode V2 세션 기록과 히트맵을 지원합니다. 기록 캐시 복원과 여러 터미널에서 대량의 출력이 발생할 때의 파싱 및 스케줄링 안정성을 개선했습니다.

메시지 연결 기능은 계속 개선 중이며, 사용 중 문제가 발생할 수 있습니다. [GitHub Issues](https://github.com/edison7009/Coffee-CLI/issues)에 문제, 의견, 제안을 남겨 이 작업 방식을 개선하는 데 함께해 주세요.
